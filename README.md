# monin 1

Учебный проект по дисциплине «Программная инженерия». В этом репозитории команда ведёт историю изменений и собирает результаты практических работ для допуска к проекту.

## Первая практическая работа

Цель — организовать совместную работу в GitHub. Основная ветка — `main`. Начальный коммит содержит описание проекта и его эмблему. Назначение проекта и порядок участия описаны на [главной странице Wiki](https://github.com/monin-1-lab/monin-1/wiki).

## Работа с материалами

Перед изменением файла проверьте, к какой практической работе он относится. В сообщении коммита укажите, что изменилось, например «Добавить описание первой практической». Решения, которые понадобятся остальным участникам, зафиксируйте в Wiki.
